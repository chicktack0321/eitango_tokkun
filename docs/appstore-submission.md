# App Store Connect 提出手順

貼り付ける文言は `store-listing.md` にある。ここでは「どこに何を入れるか」と、
間違えやすい箇所をまとめる。

App Store Connect の設定項目は**3つの階層**に分かれている。どこにあるか分からなくなったら、
まずこの区別を思い出すとよい。

| 階層 | 内容 | 変更のたびに審査が要るか |
| --- | --- | --- |
| **App情報**（App全体） | カテゴリ、年齢制限、コンテンツ配信権 | 一部要る |
| **価格と配信状況**（App全体） | 価格、配信地域 | 不要（いつでも変えられる） |
| **バージョン 1.0**（バージョンごと） | 名称、説明文、キーワード、スクリーンショット、ビルド | 要る |
| **App のプライバシー**（App全体） | データ収集の申告 | 不要 |

---

## 1. App情報

左メニュー「一般」→「App情報」

| 項目 | 入力 |
| --- | --- |
| ローカリゼーション可能な情報 → 名称 | `英単語特訓 英検®2級 4000語` |
| サブタイトル | `広告なし・通信なしで覚える単語帳` |
| プライバシーポリシーURL | `https://sites.google.com/view/eitango-tokkun/privacy-policy` |
| カテゴリ（プライマリ） | 教育 |
| カテゴリ（セカンダリ） | 辞書/辞典/その他 |
| コンテンツ配信権 | 「サードパーティのコンテンツを含まない」を選ぶ |
| 年齢制限 | 「編集」→ 質問にすべて「なし/いいえ」→ **4+** |

**「キッズカテゴリ」には登録しない。** 追加の規約と制約が発生する。

コンテンツ配信権を「含まない」にできるのは、収録している単語・訳・例文をすべて
自前で用意しているため。市販の単語帳から転記していれば別の回答が必要になる。

---

## 2. 価格と配信状況

左メニュー「価格と配信状況」

| 項目 | 入力 |
| --- | --- |
| 価格 | **無料** |
| 配信地域 | すべての国と地域（初期値のまま） |

**アプリ本体は無料。** ¥500の価格を付けるのは App内課金アイテムのほうで、
ここではない。ここを有料にすると、ダウンロードの時点で課金が必要な別のアプリになる。

配信地域を日本だけに絞る必要はない。海外在住の日本人受験者に届かなくなるだけで、
絞る利点がない。

---

## 3. App のプライバシー

左メニュー「App のプライバシー」→「編集」

「このAppはユーザーからデータを収集しますか？」→ **「いいえ」**

本アプリは通信を行わず、学習履歴も端末内にのみ保存するため、これが正確な申告になる。
製品ページに「データを収集していません」と表示され、他の学習アプリとの差になる。

---

## 4. バージョン 1.0

左メニュー「iOS App」→「1.0 提出準備中」

### 4-1. スクリーンショット

**iPhone 6.9インチ（1320×2868）のみ登録すれば足りる。** 他のサイズは自動で調整される。
本アプリはiPhone専用（`TARGETED_DEVICE_FAMILY = 1`）なので、iPad用の登録は求められない。

画像は Actions →「Store Screenshots」の成果物 `store-screenshots` から取得する。
掲載順は次のとおり（伝わる順に並べる）。

1. ホーム … 学習状況が一目で分かる
2. 単語帳 … 3,955語と絞り込み
3. 4択クイズ … 出題画面
4. タイピング … モード選択
5. 聞き流し … 速度と絞り込み
6. 学習の記録 … グラフ

### 4-2. 文言

`store-listing.md` から貼り付ける。

| 項目 | 備考 |
| --- | --- |
| プロモーション用テキスト | 審査なしでいつでも差し替えられる。試用の条件を書いておく |
| 説明文 | 冒頭に料金条件を置いた版をそのまま使う |
| キーワード | 名称に入っている語は繰り返さない（既に検索対象のため） |
| サポートURL | `https://sites.google.com/view/eitango-tokkun/support` |
| マーケティングURL | 空欄でよい |

### 4-3. ビルド

「ビルド」欄の「＋」から、TestFlight に上がっているビルドを選ぶ。
処理中は選択肢に出てこないので、表示されるまで待つ。

### 4-4. App内課金の紐付け（**忘れやすい**）

バージョンのページに「App内課金」の欄がある。ここに
**「2級コア発展語彙の解放」を追加する。**

初回の App内課金はアプリ本体と一緒に審査される。ここで紐付けを忘れると、
**アプリだけ審査を通過し、課金アイテムが未審査のまま残る**。その状態では
購入しようとしてもエラーになり、リリース後に気付くことになる。

課金アイテム側のステータスが「送信準備完了」になっていることも確認する。
スクリーンショットと審査用の説明が未入力だと、この状態にならない。

### 4-5. App Review に関する情報

| 項目 | 入力 |
| --- | --- |
| サインインが必要 | **いいえ**（ログインの仕組みが無いため） |
| 連絡先 | 氏名・電話番号・メールアドレス |
| 備考 | `store-listing.md` の「審査メモ」をそのまま貼る |

**備考は空欄にしない。** 「14日後に制限がかかる」とだけ見えると、一定期間後に
使えなくなる体験版（ガイドライン2.1）と受け取られる余地がある。
「機能は止まらず、出題される語彙の範囲が変わるだけ」であることを先に説明しておく。

### 4-6. バージョンのリリース

- 手動でリリース … 審査通過後、公開のタイミングを自分で決められる
- 自動でリリース … 通過し次第すぐ公開

**英検第2回の申込期に合わせたいので「手動でリリース」を選ぶ。**
審査がいつ通るか読めないため、自動にすると狙った時期からずれる。

---

## 5. 提出

右上「審査へ提出」。

輸出コンプライアンスの質問は出ない（`ITSAppUsesNonExemptEncryption` を
Info.plist で宣言済みのため）。

---

## 提出後によくある差し戻しと、その備え

| 指摘されうる点 | 備え |
| --- | --- |
| 体験版とみなされる（2.1） | 審査メモで先に説明。実際に機能は止まらない |
| 商標の無断使用（5.2.1） | アプリ内と説明文に権利表記。指摘されたらアイコンから「英検」を外した版に差し替える |
| 購入の復元が見つからない（3.1.1） | ホーム →「このアプリについて」と購入画面の2か所にある |
| プライバシーの申告と実態の不一致 | 通信を行わないので不一致は起こらない |

アイコン差し替えが必要になった場合に備え、「英検」を外して「2級」だけを残した版を
用意しておくと、差し戻しから再提出までが1日で済む。
