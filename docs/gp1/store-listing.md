## 説明文

冒頭に料金の条件を置く。ここを曖昧にすると「使えなくなった」という評価につながり、
Apple の「正確な説明」の要件にも触れる。

```
英検®準1級に必要な語彙4,869語を、通信なし・広告なしで学習するアプリです。
アカウント登録は不要。起動してすぐ始められます。

■ 料金について（最初にお読みください）
・最初の14日間は、すべての語彙をお試しいただけます。
・期間が終わったあとも、クイズ・タイピング・聞き流しはそのままお使いいただけます。
　変わるのは出題される語彙の範囲だけです。
・準1級コア発展語彙1,491語を出題対象に加えるには、買い切りの購入が必要です。
　月額・年額の課金はありません。
・単語帳での閲覧・検索・発音は、購入の有無にかかわらず全4,869語をご利用いただけます。

■ 3階層で整理した4,869語
・基礎（3級〜2級）2,681語
・2級帯（2級の得点源の復習）697語
・準1級コア発展語彙 1,491語 ← 試験で直接問われる層
出題対象の語には全語に例文が付いています。熟語・句動詞は447語を収録。
社会・政治・経済・科学技術・医療・教育など、準1級で実際に出題される分野で絞り込めます。

■ 忘れかけた単語だけが出てくる
正解するたびに復習の間隔が 1日 → 3日 → 7日 → 14日 → 30日 と伸びます。
間違えた語はその日のうちにもう一度出ます。
「覚えた」が付くのは7日以上あけて思い出せた単語だけ。
直前に1回正解しただけでは付きません。翌日には忘れている単語を
「覚えた」に数えないための設計です。

■ 4つの学習方法
・4択クイズ … 15問1セット。1問10秒の制限時間つき
・タイピング … 60秒のタイムアタック。綴りを伏せる「ブラインド」モードも
・聞き流し … 画面を消しても再生が続きます。速度は0.8〜2.0倍
・単語帳 … 頻出度・品詞・分野・階層・学習状況で絞り込み

■ 自分の単語を追加できます
覚えたい単語を追加すると、クイズ・タイピング・聞き流しにもそのまま出てきます。
追加時には端末の辞書で綴りを確認し、間違いが疑われるときは候補を表示します。

■ 学習の記録
解答数の棒グラフと習熟度の折れ線を、2週間から1年まで切り替えて確認できます。
連続学習日数も表示します。

■ 通信を一切行いません
単語データも音声も端末内で完結します（読み上げはiOS標準の音声合成機能）。
学習履歴が外部に送られることはなく、個人情報は一切収集しません。
電波の届かない場所でも、機内モードでもそのまま使えます。

※学習履歴は端末内にのみ保存されるため、端末間での同期はできません。

英検®は公益財団法人 日本英語検定協会の登録商標です。
本アプリは同協会が承認・許諾したものではありません。
```

## 審査メモ（App Review に関する情報 → 備考）

**貼り付ける文面は `docs/gp1/app-review-notes.md` にある。** 2級の初回審査で受けた
2.1（Information Needed）の8項目を、最初から備考に入れて提出する。

要点:

- アカウント登録・ログイン・アカウント削除は無し（利用者のアカウントを一切持たないため）
- 権限要求は無し。Info.plist に usage description 文字列を持たない
- 外部サービス・解析・広告SDK・サードパーティSDKは一切使用していない
- 地域による違いは無い。UIは日本語のみ、配信は全世界
- 収録語・訳・例文はすべて自作。英検の問題や市販教材からの転載は無い
- 「英検®」は登録商標。協会とは無関係である旨をアプリ内とストア説明文に明記している
- App内課金は非消耗型1つのみ。試用版ではなく、期間後も全機能が動く
