## 1. Googleサイトの更新

既存サイト `sites.google.com/view/eitango-tokkun` に手を入れる。
**プライバシーポリシーのURLパス `privacy-policy` は全アプリに焼き込み済みなので変更しない。**

### 1-1. プライバシーポリシーをシリーズ共通の文面にする

収集しない・通信しないという設計は全エディションで同じなので、ページは1枚を共用する。
現行文面の「対象」の行だけを差し替える。

差し替え前:

```
対象: iPhoneアプリ「英単語特訓 英検®2級」
```

差し替え後:

```
対象: iPhoneアプリ「英単語特訓」シリーズ各アプリ
　　（英検®2級 / 英検®準2級 / 英検®3級 / 英検®4級）
```

あわせて最終更新日を更新し、課金に触れている段落に無料アプリの但し書きを足す。

差し替え前:

```
ただし、App内課金の購入・復元の際にのみ、Appleのサーバーとの通信が発生します。
```

差し替え後:

```
ただし、App内課金のあるアプリ（英検®2級 / 英検®準2級）で購入・復元を行うときにのみ、
Appleのサーバーとの通信が発生します。英検®3級 / 英検®4級はApp内課金がないため、
この通信も発生しません。
```

### 1-2. サポートページを級ごとに作る

語数・級名・課金の有無が違うので、ページはアプリごとに分ける。
既存の `support`（2級）はそのまま残し、3ページを新規に追加する。

| ページ | URLパス | 元にする文面 |
| --- | --- | --- |
| サポート（準2級） | `support-gp2` | 既存 `support` をそのまま。語数を3,325語・1,182語に、級名を準2級に置換 |
| サポート（準1級） | `support-gp1` | 同上。語数を4,869語・1,491語に、級名を準1級に、価格を¥600に置換 |
| サポート（1級） | `support-g1` | 同上。語数を5,006語・1,219語に、級名を1級に、価格を¥800に置換 |
| サポート（3級） | `support-g3` | 下記の無料版テンプレート。語数1,686語 |
| サポート（4級） | `support-g4` | 下記の無料版テンプレート。語数980語 |

**URLパスを間違えるとアプリ内の「使い方・お問い合わせ」が404になる。**
パスは `Editions/<ID>/Edition.swift` の `supportURL` と一字一句合わせること。

#### 無料版サポートページの本文（3級の例。4級は語数と級名を置換する）

```
英検®3級の語彙1,686語を、無料・通信なし・広告なしで学習するアプリです。
単語帳・4択クイズ・タイピング・聞き流しを、すべて端末内で完結して使えます。

■ 料金について
すべての機能と全語彙を無料でお使いいただけます。
App内課金はありません。広告も表示しません。
アプリ内で購入を求められることは一切ありません。

■ 出題される語彙の範囲
3つの階層に分けて収録しています。

・基礎（5級以下）297語 … すでに知っている前提の語。既定では出題しません
・4級帯 589語
・3級コア語彙 800語

クイズ・タイピング・聞き流しでは、既定で「4級帯」と「3級コア語彙」が出題されます。
基礎の語も、出題範囲の設定から選べば出題できます。
単語帳ではどの階層も閲覧・検索・発音できます。

■ 学習の記録は他の端末に引き継げますか？
いいえ。本アプリは通信を行わず、学習履歴を端末内にのみ保存する設計のため、
端末間での同期はできません。アプリを削除すると履歴も消えます。

■ 「覚えた」はどうすれば付きますか？
直前に正解しただけでは付きません。正解するたびに復習の間隔が
1日 → 3日 → 7日 → 14日 → 30日 と伸び、7日以上の間隔に到達した単語が「覚えた」になります。
翌日には忘れている単語を「覚えた」に数えないための設計です。
間違えると間隔は最短に戻ります。

■ 「覚えた」が減ることがあります
仕様です。復習の期限が来た単語は「要復習」に戻ります。
忘却を無視して数字だけが増え続ける表示は学習の役に立たない、という考えによるものです。

■ 画面を消しても聞き流しは続きますか？
続きます。イヤホンやスピーカーで再生したまま画面をロックしても止まりません。

■ 単語を自分で追加できますか？
できます。単語帳の右上「＋」から追加すると、クイズ・タイピング・聞き流しにも
そのまま出てきます。追加時には端末の辞書で綴りを確認し、
誤りが疑われる場合は候補を表示します。固有名詞などはそのまま登録できます。

■ 上の級のアプリはありますか？
「英単語特訓」シリーズとして、準2級・2級も公開しています。
App Store で「英単語特訓」と検索してください。

■ 収録語彙の訳や例文に誤りを見つけました
下記のお問い合わせフォームからお知らせください。アップデートで修正します。
単語データを更新しても、学習履歴は保持される設計になっています。

■ お問い合わせ
不具合のご報告・ご要望・語彙の誤りのご指摘は、下記のフォームからお願いします。

お問い合わせフォーム
（フォームのURL）

Googleアカウントへのログインは不要です。
ご返信をご希望の場合は、フォーム内の「返信先メールアドレス」欄にご入力ください。
空欄のままでもご送信いただけます（その場合、個別のご返信はできません）。
ご返信には数日いただく場合があります。
```

> 貼り付けたあと、`お問い合わせフォーム` の行を選択して Googleサイトのリンク機能で
> フォームのURLを設定し、`（フォームのURL）` の行は削除する。

### 1-3. お問い合わせフォームに「対象アプリ」を足す

フォームは1つを全アプリで共用する。どのアプリについての問い合わせか分からないと
語彙の誤りの指摘を直せないため、**先頭に質問を1つ追加する**。

| # | 質問 | 形式 | 必須 | 選択肢 |
| --- | --- | --- | --- | --- |
| 0（先頭に挿入） | どのアプリについてですか | ラジオボタン | ○ | 英検®2級 / 英検®準2級 / 英検®3級 / 英検®4級 |

既存の質問1〜5はそのまま。フォームのタイトルと説明も級名を外して一般化する。

タイトル:

```
英単語特訓 お問い合わせ
```

説明:

```
「英単語特訓」シリーズ各アプリについて、不具合のご報告、ご要望、
収録語彙の誤りのご指摘をお送りいただけます。
Googleアカウントへのログインは不要です。
ご返信をご希望の場合のみ、最後の欄にメールアドレスをご入力ください。
```

**設定は触らないこと。**「メールアドレスを収集する」を有効にするとGoogleアカウントへの
ログインが必須になり、ログインしない審査担当者がフォームを開けず差し戻しになる
（`docs/site-content.md` の該当節を参照）。

### 1-4. 公開前に確認する

シークレットウィンドウで、ログインしていない状態で次を開く。

- `/privacy-policy` … 対象の行がシリーズ表記になっていること
- `/support-gp2` `/support-g3` `/support-g4` … 404 にならないこと
- フォーム … ログインを求められずに送信できること

## 2. App Store Connect（3本に共通）

`docs/appstore-submission.md` の手順をそのまま使う。アプリを新規登録するところから始める。

- **バンドルIDは先に Developer サイトで作る**。App Store Connect の新規App作成では
  既存のバンドルIDしか選べない
- 「App情報」「価格と配信状況」「Appのプライバシー」は2級と同じ入力でよい。
  プライバシーは**データを収集しません**
- 名称・サブタイトル・キーワード・説明文は `docs/<id>/store-listing.md` から貼る

### 無料の2本（3級・4級）で省ける手順

| 2級の手順 | 無料アプリでは |
| --- | --- |
| 4-4 App内課金の登録 | **不要** |
| 4-4 審査用スクリーンショットの添付 | **不要** |
| 4-4 バージョンページでの課金アイテム紐付け | **不要**（2級で忘れやすいと書いてある箇所） |
| 2 価格と配信状況 | 価格を「無料」にする |

**バージョンページで課金アイテムを紐付ける**。紐付けを忘れると「送信準備完了」にならない。

## 4. 提出の順番

**準2級を先に出す。** 課金のあるアプリのほうが審査で見られる項目が多く、
2級の初回で受けた 2.1（Information Needed）と同じ質問が来る可能性が高い。
準2級で備考の文面を確定させてから、無料の2本に流用するほうが手戻りが少ない。

無料の2本は同時に出してよい。中身の差は語彙データだけで、審査で聞かれることも同じ。

**上位級（準1級・1級）はそのあと。** 課金の手順は準2級と同じで、確定した備考の文面を
そのまま流用できる。先に出す理由が無く、審査を同時に何本も走らせると、指摘が来たときに
どのビルドの話か追いにくくなる。

**審査中は main のコードを変更しない。** 審査対象のビルドと手元のコードがずれると、
追加質問への回答や再提出で何を出したのか分からなくなる。作業はブランチに積む
（Phase 0 で実際にそうした。`docs/series-implementation-handoff.md` §1）。
