# 公開ページの文面（Googleサイト貼り付け用）

App Store Connect には「プライバシーポリシーURL」と「サポートURL」の登録が必須で、
どちらも**ログインなしで誰でも開ける**必要がある。

GitHub Pages ではなく Googleサイトで公開する。App Store Connect に
`github.io` のURLを載せるとソースの所在が分かってしまうため。

以下はそのまま貼り付けられる本文。HTMLタグは使わず、Googleサイトの見出し機能で
「■」の行を見出しにすればよい。

## ページ3: サポート

**ページのURLパスは `support` にする**。

見出し（大）:

```
サポート
```

本文:

```
英検®2級の語彙3,955語を、通信なし・広告なしで学習するアプリです。
単語帳・4択クイズ・タイピング・聞き流しを、すべて端末内で完結して使えます。

■ お試し期間と購入について
最初の14日間は、すべての語彙をお試しいただけます。
期間が終わったあとも、アプリの機能はすべてそのまま使えます。
変わるのは出題される語彙の範囲だけです。

・お試し期間中（14日間）… 全3,955語が出題対象
・期間終了後（未購入）… 基礎・架け橋の語彙が出題対象
・購入後… 全3,955語（期限なし）

期間終了後にロックされるのは、2級コア発展語彙（1,274語）の出題だけです。
単語帳での閲覧・検索・発音は、購入の有無にかかわらず全3,955語をご利用いただけます。

■ 買い切りです
月額・年額の課金はありません。一度購入すれば期限なくご利用いただけます。

■ 機種変更したとき・アプリを入れ直したとき
同じApple アカウントであれば、アプリ内の「購入を復元」から無料で復元できます。
再度購入する必要はありません。
ホーム画面 →「このアプリについて」→「購入を復元」から行えます。

■ 学習の記録は他の端末に引き継げますか？
いいえ。本アプリは通信を行わず、学習履歴を端末内にのみ保存する設計のため、
端末間での同期はできません。アプリを削除すると履歴も消えます。

■ 「覚えた」はどうすれば付きますか？
直前に正解しただけでは付きません。正解するたびに復習の間隔が
1日 → 3日 → 7日 → 14日 → 30日 と伸び、7日以上の間隔に到達した単語が「覚えた」になります。
翌日には忘れている単語を「覚えた」に数えないための設計です。
間違えると間隔は最短に戻ります。

■ 「覚えた」が減ることがあります
仕様です。復習の期限が来た単語は「要復習」に戻ります。
忘却を無視して数字だけが増え続ける表示は学習の役に立たない、という考えによるものです。

■ 画面を消しても聞き流しは続きますか？
続きます。イヤホンやスピーカーで再生したまま画面をロックしても止まりません。

■ 単語を自分で追加できますか？
できます。単語帳の右上「＋」から追加すると、クイズ・タイピング・聞き流しにも
そのまま出てきます。追加時には端末の辞書で綴りを確認し、
誤りが疑われる場合は候補を表示します。固有名詞などはそのまま登録できます。

■ 収録語彙の訳や例文に誤りを見つけました
下記の窓口までお知らせください。アップデートで修正します。
単語データを更新しても、学習履歴は保持される設計になっています。

■ お問い合わせ
不具合のご報告・ご要望・語彙の誤りのご指摘は、こちらまでお願いします。

（ここにメールアドレスを記載してください）

ご返信には数日いただく場合があります。
```

## Googleサイトでの手順

1. https://sites.google.com を開き、**空白のサイト**を作成する
2. サイト名を「英単語特訓 英検®2級」にする
3. 右のメニュー →「ページ」から `プライバシーポリシー` と `サポート` を追加する
4. 各ページの右クリック →「プロパティ」で**URLパスを `privacy` / `support` に変更**する
5. 上の本文を貼り付ける（「■」で始まる行は見出しにすると読みやすい）
6. 右上「公開」→ **ウェブアドレス**を決める（例: `eitango-tokkun`）
7. **公開設定で「閲覧できるユーザー」を「公開（ウェブ上の全員）」にする**

### 手順7が最重要

ここを既定のままにすると、**ログインしないと開けないページ**になる。
審査担当者はログインできないので、URLが開けないという理由で差し戻される。

公開後、シークレットウィンドウ（ログインしていない状態）でURLを開いて
確認すること。ここだけは必ず自分の目で見ておく。

### 公開後にお知らせいただく情報

次の2つのURLをお知らせください。アプリに埋め込みます。

```
https://sites.google.com/view/（決めたアドレス）/privacy
https://sites.google.com/view/（決めたアドレス）/support
```

---

## 注意点

- **メールアドレス**をサポートページに記載する必要がある。App Store Connect の
  審査用連絡先とは別に、利用者からの問い合わせ窓口として公開するもの
- Googleサイトの独自ドメインは任意。`sites.google.com/view/...` のままでよい
- 公開後にページを編集した場合、**再度「公開」を押さないと反映されない**
