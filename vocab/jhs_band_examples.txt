# 中学基礎帯（4級帯）の例文。G4 の bridge/core と G3 の bridge に使う。
#
# 形式: <word> | <例文>
# word は master.json の word フィールドと完全一致させること（key は機械的に解決する）。
#
# なぜ canonical ではなく override なのか:
#   ここに挙げた語は公開中の2級アプリでは basic（既習語）で、例文を持たない。
#   canonical の example に書くと2級の同梱 seed が変わり、再現一致ゲートが落ちる。
#   したがって editions.G4 / editions.G3 の example として与える（仕様書§5）。
#
# 書式（仕様書§6）:
#   - 1文で完結。4〜10語。クイズ画面は2行で打ち切るため長文は不可
#   - A1帯の語だけで組む。見出し語以外に難しい語を入れない
#   - 見出し語をそのままの形で含める（活用形の変化は可）
#   - 固有名詞・時事ネタ・特定の文化前提を避ける
